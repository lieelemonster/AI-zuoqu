# AI 写词与作曲产品 PRD（第二版）

## 1. 产品目标

面向短视频创作者和音乐爱好者，根据用户的创作想法生成中文歌词，再生成与歌词对应的旋律及简单伴奏，输出可试听、下载的音乐小样。

首版用于自行验证创作流程和生成效果。

## 2. 本版调整

- 歌曲生成改为旋律与简单伴奏生成。
- 使用 MIDI＋乐器音源实现音乐试听和音频导出。
- 主旋律使用钢琴音色，搭配简单和弦伴奏。
- 暂不包含女声演唱，输出为无演唱的音乐小样。
- 保留 3 版歌词、手动编辑、单版音乐生成与重新生成。

技术实现采用已选择的方案二：AI 规划音乐方向，程序按规则生成音符与伴奏。具体实现见《方案二_AI规划与规则作曲技术文档》。

## 3. 用户流程

填写创作信息 → 生成 3 版歌词 → 选择并手动编辑 → 生成音乐小样 → 试听 → 下载或重新生成。

用户可以返回修改歌词或创作信息，再次生成音乐。

## 4. 功能需求

### 4.1 创作信息输入

| 字段 | 要求 | 预设选项 |
|---|---|---|
| 主题 | 必选，单选 | 爱情、友情、亲情、青春校园、成长追梦、治愈鼓励、回忆怀念、故乡、旅行、日常生活 |
| 情绪 | 必选，单选 | 甜蜜、快乐、悲伤、思念、温暖、轻松、孤独、怀旧、热血、充满希望 |
| 音乐风格 | 必选，单选 | 流行、民谣、国风、摇滚、R&B、电子、说唱 |
| 故事描述 | 选填，文本输入 | 补充人物、经历、场景或想表达的内容 |

主题、情绪、风格仅提供预设，不支持自定义。中文和目标时长作为固定条件。

本版的音乐风格主要通过节奏、速度、和弦及旋律体现，统一使用钢琴主旋律与简单伴奏。

### 4.2 歌词生成

根据创作信息，一次生成 3 版中文歌词：

| 版本 | 表达侧重点 |
|---|---|
| 故事叙述版 | 事件、人物和故事发展 |
| 情绪表达版 | 感受与情绪 |
| 意象表达版 | 场景、画面和意象 |

生成要求：

- 三个版本保持主题、情绪和风格一致。
- 标注主歌、副歌，篇幅适合约 1 分钟音乐。
- 副歌突出核心主题，具有记忆点。
- 句式适合配旋律；说唱风格侧重节奏。
- 用户填写故事描述时，应融入相关细节。

### 4.3 歌词选择与编辑

- 用户选择一个版本用于作曲。
- 支持直接手动编辑选定歌词。
- 使用最新编辑内容生成音乐。
- 歌词为空时，禁止生成音乐。
- 修改歌词后，已有音乐不会自动更新，需点击生成按钮。

### 4.4 音乐小样生成

根据最终歌词及创作信息，每次生成 1 版音乐小样。

| 项目 | 要求 |
|---|---|
| 时长 | 45～75 秒 |
| 结构 | 包含主歌、副歌及自然结尾 |
| 主旋律 | 钢琴音色演奏 |
| 伴奏 | 简单和弦伴奏 |
| 歌词适配 | 根据分句、字数和段落安排乐句、节奏及停顿 |
| 副歌表现 | 与主歌形成可辨识的变化 |
| 情绪与风格 | 通过音乐参数体现用户选择 |
| 演唱 | 不包含人声演唱 |
| 数量 | 每次 1 版 |

说唱风格主要根据歌词安排节奏，钢琴提供简单动机与和声，不要求逐字对应旋律音高。

### 4.5 试听、重新生成与下载

- 生成成功后提供播放、暂停和进度拖动。
- “重新生成”使用当前歌词与创作信息，生成新的旋律和伴奏，不修改歌词。
- 新结果成功后替换当前试听结果；失败时保留已有结果。
- 支持下载当前音乐小样，格式为 MP3。

## 5. 页面结构

采用一个创作页面，依次展示：

| 区域 | 内容 |
|---|---|
| 创作信息区 | 主题、情绪、风格、故事描述及“生成歌词”按钮 |
| 歌词区 | 三版歌词、版本选择、选定歌词编辑框及“生成音乐小样”按钮 |
| 音乐区 | 音频播放器、“重新生成”和“下载音频”按钮 |

音乐区明确标注：**钢琴旋律与伴奏小样，无人声演唱。**

## 6. 状态与异常处理

- 生成期间显示“歌词生成中”或“音乐生成中”，禁止重复提交对应请求。
- 失败时提示重试，保留当前输入、编辑内容和已有音乐。
- 修改创作信息或歌词不自动触发生成。
- 已有音乐生成后修改输入，提示“内容已修改，需重新生成音乐”。

## 7. 实现方案

文本模型生成歌词及音乐规划 → 程序按规则生成音符与伴奏 → 校验音符、节奏和结构 → 生成 MIDI → 使用乐器音源渲染 → 输出 MP3。

作曲数据包含音高、时值、速度、和弦及段落结构。校验需检查音符范围、时值合法性、旋律与伴奏对齐，以及总时长。

MIDI 作为内部生成格式，本版仅向用户提供音频下载。

## 8. 验收标准

| 验收项 | 通过标准 |
|---|---|
| 输入 | 必选字段未选择时，提示补充 |
| 歌词生成 | 返回 3 版中文歌词，侧重点可区分，均包含主歌与副歌 |
| 歌词编辑 | 可以选定并修改，作曲使用最新内容 |
| 音乐生成 | 每次生成 1 版 45～75 秒的钢琴旋律与简单伴奏 |
| 结构 | 主歌、副歌可辨识，结尾自然 |
| 歌词适配 | 乐句与歌词分句基本对应，停顿合理 |
| 音乐质量 | 无明显错拍、伴奏错位或异常中断；情绪与风格表现需人工试听验证 |
| 试听与下载 | 正常播放、暂停、拖动，并可下载可播放的 MP3 |
| 重新生成 | 更新音乐结果，不修改歌词 |
| 异常处理 | 失败可重试，不丢失当前内容和已有结果 |

## 9. 不包含的功能

人声演唱、完整歌曲生成 API、AI 修改歌词、多版音乐同时生成、专业编曲与混音、分轨及乐谱导出、账号与付费、作品库、分享和多人协作。
