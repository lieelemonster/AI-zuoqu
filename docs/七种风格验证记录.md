# 七种风格验证记录（任务 23）

## 验证方法

运行 `bash scripts/dev.sh check-styles`。每种风格搭配一个主题和情绪，走与线上相同的流程：

1. 用 mock 文本模型生成三版歌词，取“故事型”一版（主歌 4 句 + 副歌 4 句，每句约 7～8 字，属于短歌词）。
2. AI 音乐规划（mock）→ 规则作曲 → FluidSynth 渲染 → MP3。
3. 自动统计指标，并把成品保存到 `runtime/checks/styles/<风格ID>.mp3` 供试听。

| 风格 | 主题 / 情绪 |
|---|---|
| pop 流行 | 爱情 / 甜蜜 |
| folk 民谣 | 家乡 / 怀旧 |
| guofeng 国风 | 回忆 / 思念 |
| rock 摇滚 | 梦想 / 热血 |
| rnb R&B | 爱情 / 孤独 |
| electronic 电子 | 旅行 / 快乐 |
| rap 说唱 | 梦想 / 充满希望 |

自动判定的合格线：时长 45～75 秒；有主歌和副歌；每个字都有音符；结尾落在主音并衰减 ≥ 20 dB；旋律比伴奏响 ≥ 3 dB；非说唱风格副歌平均音高比主歌高 ≥ 1 个半音；最大跳进 ≤ 12 个半音；同音重复 ≤ 30%（说唱 ≤ 45%）；时值种类 ≥ 3。

## 第一次运行发现的问题

| 风格 | 问题 | 原因 |
|---|---|---|
| 摇滚 | 旋律只比伴奏响 0.1 dB，几乎被伴奏盖住 | 摇滚伴奏织体 `pulse` 是八分音符低音加每拍和弦，音符数约为其他织体的 3 倍，力度却相同 |
| 摇滚 | 结构为 `verse16 → chorus16`，每句被拉到 4 小节（约 7.5 秒一句），没有前奏，听感拖沓；同音重复 36% | 128 BPM 下短歌词不够一分钟，只能把每句拉长 |
| 电子 | 时长 47.7 秒，贴近 45 秒下限 | 同上：速度快、歌词短，又不想过度拉长 |

## 修正

1. **短歌词可以再唱一遍副歌**（`backend/app/composer/arrangement.py`）：段落分配在搜索速度、拉伸级别、前奏/尾奏长度时，多了“末尾重复最后一段副歌”这个选项（带 2.5 分罚分）。只有比拉长每句更合适时才会选中，慢风格或歌词够长时不会重复。重复段使用新 ID（`chorus_1_repeat`），节奏和旋律沿用第一遍副歌，形成可记忆的副歌。
2. **密集伴奏降低力度**（`backend/app/composer/accompaniment.py`）：`pulse` 织体力度 −14，`offbeat` 织体力度 −4，让主旋律始终比伴奏响。
3. 测试：`test_melody.py` 的字音对应检查改为按实际演唱的歌词行（含重复副歌）计数；`test_arrangement.py` 新增“快风格短歌词会重复副歌且旋律一致”“慢风格歌词够长时不重复”两个用例。

## 情绪、节奏与歌词贴合情况

- **情绪**：悲伤、思念、孤独类情绪落在小调，速度在风格范围内偏慢（R&B 68、国风 75）；热血、快乐偏快偏响（摇滚、电子 128）。速度区分明显，调式随情绪切换正确。
- **节奏**：民谣、国风、R&B 每秒约 1 个字，比较舒缓；流行约 1.5 个字；电子、摇滚约 2 个字；说唱约 2.4 个字、反拍占 71%，节奏型和其他风格差别明显。电子副歌比主歌更密（2.3 对 1.9），有推进感。
- **歌词贴合**：每个字都有且只有一个旋律音，句尾留有停顿；副歌比主歌平均高 4～7 个半音，听得出副歌抬起来了。
- **已知限制**：
  - R&B（68 BPM）短歌词已接近一分钟，没有空间加前奏，开头直接进主歌旋律。
  - 摇滚副歌 7 小节是按每句自然长度拼出来的，不是整齐的 8 小节。
  - 只有钢琴单一音色，无人声；摇滚、电子的“力度感”主要靠速度和伴奏织体体现，和真实乐队相比差距明显。这是方案二的预期范围。

## 试听清单（请人工逐一确认）

运行 `bash scripts/dev.sh check-styles` 后，依次执行 `open runtime/checks/styles/<风格ID>.mp3`，风格 ID 为 `pop`、`folk`、`guofeng`、`rock`、`rnb`、`electronic`、`rap`。每首确认：

- [ ] 能听出主歌和副歌的区别（副歌更高、更满）
- [ ] 结尾停在一个稳定的和弦上，声音自然消失，没有突然切断
- [ ] 旋律清楚，没有被伴奏盖住
- [ ] 速度和情绪大致符合（例如国风“思念”舒缓偏暗，电子“快乐”轻快明亮）
- [ ] 摇滚、电子、说唱：副歌唱了两遍，第二遍旋律和第一遍相同
